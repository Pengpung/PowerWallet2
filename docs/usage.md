# 使用与恢复

## 连接手机

打开 Windows EXE 后，工具会自动检查内置文件完整性并检测设备。请使用能传输数据的 USB 线，开启手机的 USB 调试，并在手机上允许电脑授权。

多个设备同时连接时，从“手机连接”下拉列表选择正确的手机。工具显示机型，不把完整设备序列号放到界面或操作日志中。

本 fork 已验证小米 13 Ultra 的国行 `OS3.0.308.0.WMACNXM` 和红米 Turbo 4 Pro 的 `OS3.0.306.0.WOLCNXM`。其他 HyperOS 版本会按通用模式尝试激活；非 HyperOS 固件不会激活。

## 安装并激活

手机需要先安装并设置 Google 钱包。点击“安装并激活”，工具会再次检查连接及兼容性，停止旧助手、安装签名 APK、传输助手并启动，然后查询实时状态。

若手机弹出安装确认，请在手机完成。若出现 USB 安装被限制的提示，按手机开发者选项中相关设置处理后重试。电脑工具不会代替你更改手机安全设置。

显示“钱包快捷键已就绪”后，可拔掉数据线。双击电源键将打开 Google 钱包卡片页面。未解锁时按 Google 钱包要求完成验证。

手机重启会结束 ADB 助手。再次使用时可用手机端 Shizuku 点击“用 Shizuku 重新激活”，或连接电脑后点击“安装并激活”。电脑端不需要一直开着。

## 深色模式与屏幕适配

顶部可选择跟随系统、深色或浅色。选择会保存在当前 Windows 用户的 `%LOCALAPPDATA%\PowerWallet\theme.txt`。

程序读取显示器工作区与缩放比例，不更改系统分辨率。窗口会限制在可用工作区内，在不同 DPI 显示器间移动时重新检查尺寸。较窄窗口会换行排列操作按钮；可用高度较小时可滚动访问内容。

后台自动刷新不会禁用激活、恢复或打开插件按钮。实际执行操作时才会暂时禁用这些按钮，避免重复操作。恢复完成后会显示是否恢复原快捷键或保留了你后来选择的新设置。

## 恢复原快捷键

连接手机后点击“停用并恢复”，或在手机插件中点击“停用并恢复”。助手仍在运行时通过 Binder 恢复；助手已被系统清理时，手机端会自动改用 Shizuku 的 shell 身份读取备份并恢复。助手会停止，恢复激活前保存的设置。

如果手机已经重启，Windows 工具仍可读取手机上保存的备份并恢复。若快捷键已由你改为其他操作，会保留你的新选择；如果备份缺失，不会猜测原设置。

恢复后可卸载手机上的“电源键钱包”。关闭 Windows EXE 不会停止手机助手。

## 本地文件

EXE 首次运行会把 ADB、USB DLL、APK 与许可声明解包到当前用户的 `%LOCALAPPDATA%\PowerWallet\assets\desktop-2.0.0`，后续会核对内容哈希。无需管理员权限。

手机端助手与快捷键备份位于 `/data/local/tmp/powerwallet-*`。操作日志只在电脑窗口中显示，不上传外网。APK 不读取银行卡信息。
